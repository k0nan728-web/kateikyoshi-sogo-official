# 英検サイト 受付導線・送信品質の改善（2026-11-02）

## 改善した内容

- 目標級チェックの級・課題・受検時期を、相談フォームへ引き継ぐ。級別7ページからも対象級を渡す。
- 相談と申込の切替時も、対象級と専門ブランドを保持する。申込時の級が未定なら、準1級を勝手に選ばない。
- URLから引き継ぐのは許可された学習上の選択肢だけ。氏名・メール・相談文などの個人情報はURLやブラウザ保存領域に保存しない。
- 本文へのスキップリンクを追加。ヒーローで無料相談と有料体験の違いを明示。料金表近くで学年不問・90/120分の倍率・任意サポートを確認できるようにした。
- 2000文字の相談文が通知では1200文字に切れていた問題を修正し、全文を通知に含める。空欄・2000文字超は送信先でも拒否。
- 受付通知と自動返信の成否を区別。講師宛通知だけ成功した場合は、再送不要である旨を完了画面に表示する。
- 通信の再試行に同一の送信識別子を使い、ResendのIdempotency-Keyで通知・自動返信の二重発行を防ぐ。フォーム内容を変更した場合は別の識別子にする。
- 外部認証・メールAPIに10秒、フォーム通信に35秒の上限を設定。認証機能は維持。
- 未設定・送信失敗時の古いGoogleフォームへの転送を削除。入力を残して明示的なメール用コピーを案内する。コピーだけで送信完了と表示しない。
