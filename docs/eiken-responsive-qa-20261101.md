# 英検合格ゼミナール 表示・操作検証（2026-11-01）

## 確認した不具合と修正

- 級別ガイド全7ページ：情報グリッドの最小幅280pxが、320px画面のカード内幅を超え、本文が右に20pxはみ出す。最小トラック幅を利用可能幅以下に制限。
- 同ページ：小型画面で「無料相／談」や見出しの「ド」だけが別行になる。ヘッダーの役割別縮小・相談ボタンの折返し防止・見出しの意味単位化で修正。mainランドマークを設け既存の改行調整を適用。
- 目標級チェック：5級・4級でも「英作文・面接」と案内。級によって選択肢と結果を変更し、録音式スピーキングと級認定の違いを表示。
- 申込フォーム：bodyの固定最小幅320pxがスクロールバー付き320px画面の利用可能幅305pxを超える。固定最小幅を解除。共通CSSのURLバージョンを更新。
- 動きを抑える設定では、英検トップと級別ページのスムーズスクロール・対象装飾アニメーションを停止するCSSを追加。

教材表紙は元画像と照合。正方形画像の余白を除く既存表示で、実際の表紙に欠けがないため変更しない。

## 検証方法と結果

Chromeの実ブラウザで、検証専用ページのiframe幅を操作し、埋め込んだ本番／修正版のCSS viewportを変更。各viewportのinnerWidth、documentElement.clientWidth/scrollWidth、画面外へ出る要素をDOMから読み取り、主要状態を目視確認した。検証ページは公開コードに含めない。

- トップ：320,360,375,390,414,430,539,540,541,559,560,561,599,600,601,649,650,651,679,680,681,699,700,701,720,721,744,759,760,761,768,810,820,834,835,849,850,851,899,900,901,1023,1024,1099,1100,1101,1199,1200,1280,1366,1440,1920pxの52幅。修正版は横はみ出しなし。
- 級別7ページ：各320,360,375,390,414,430,600,744,768,820,834,1024,1280,1440,1920pxの15幅。修正版は横はみ出しなし。
- 相談／申込フォーム：320,390,768,1024,1920px。修正版はページ横スクロールなし。意図的に画面外へ配置されたスパム対策入力は表示不具合に数えない。
- メニュー：320,390,768,1024pxで料金アンカー移動後の自動閉鎖、Escapeによる閉鎖を確認。
- FAQ：5項目すべての開閉を確認。
- 目標級チェック：7級×3課題×3期間の63通りで対象級・期間・5級4級の補足を確認。
- 級別リンク7件の本番遷移、トップ内アンカーの参照先、読込済み画像を確認。
- 申込フォーム：架空の値をローカル修正版にのみ入力。未入力時のエラー、指導内容→日程→最終ステップ、戻った際の入力保持、5分刻み選択肢を確認。送信・規約同意・CAPTCHA操作は行っていない。
- node --test intake/validate.test.mjs intake/native-delivery.test.mjs：合格。git diff --check：合格。初回のテスト実行は作業ディレクトリ指定不足で失敗し、リポジトリルートで再実行して合格。
- 既存form-smoke.test.mjsはPlaywright依存がなく実行不可。代わりに上記実ブラウザのフォーム入力・ステップ操作で確認した。

## 検証の範囲

有限の代表幅とCSS境界幅を検証したもので、全ての整数幅での操作や、iPhone/iPad実機・Safariでの検証を意味しない。実際の送信・メール到着、支払い・契約条件、試験構成全体の監査は今回の検証対象外。料金条件は変更していない。
