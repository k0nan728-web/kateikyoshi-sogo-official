# 比較ページの操作性・境界幅の追加改善

対象: /hikaku/。前回の写真・図解を使った改修を維持して追加修正。

- 料金試算でコースを変えたとき、比較欄の目的も連動。英検、大学受験、通信制高校、学校補習の切り替えを確認。該当する公開料金のないコースは全件表示とし、対応コースだと推測しない。
- スマホのヘッダーに料金試算・他社比較・指導体制のアンカーを表示。入力欄内に追従する合計額と内訳へのリンクを追加。リンク先のスクロール・フォーカス移動を確認。
- 合計額の前提を「1回分 × 月の回数 × 期間」で図式化。任意の伴走費は別行。英検2級90分×月4回×6か月＋伴走費＝294,000円、大学受験上位区分120分×月8回×12か月＋伴走費＝1,656,000円をブラウザーで確認。
- 横はみ出しが発生しなくても601pxでヘッダー・見出しが細かく改行される問題を視認して修正。700px以下は縦配置。701〜850pxの導入写真は横長にし、顔の見切れを軽減。
- JavaScript無効時に公式料金・無料相談への導線を表示するnoscriptを追加。HTML上の存在を確認。
- Chromeのiframeで320/375/390/600/601/620/700/768/834/1024/1100/1366/1920pxの13幅を実測。全17比較カードと7桁の試算額を表示して横はみ出しなし。
- TypeScriptチェック、既存の16通りの料金計算テスト、静的ビルドが成功。
- 実機Safariとブラウザーの200%ズームは直接検証していない。画面幅の検証と混同しない。
