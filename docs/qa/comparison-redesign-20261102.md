# 料金比較ページの写真・図解を使った改修（2026-11-02）

対象: https://kateikyoshi-sogo.com/hikaku/
編集元: k0nan728-web/prokatekyo-lesson-fee-source

## 変更

- 写真付きの導入と3つのページ内導線、料金シミュレーター、比較の読み方を説明するイラストと図解、目的別の他社料金カード、指導体制、学習計画・レポートのサンプルを配置。
- 他社17件の公開料金と追加費用・適用条件・公式出典を保持。初期表示は英検3件。料金順ランキングや異なる期間・形態の不適切な換算を行わない。
- 英検の2026-10-17の公表済み訂正を保持（英検コーチの推測年額を削除、イーオンの教材込み内訳、英検協会の月払い・試験対策講座との区別）。今回、他社の価格調査日は更新していない。
- 重複していたスタイルを単一のレスポンシブ設計へ置換。価格・条件は隠さず表示。
- 直前／少回数の英検料金計算を独立関数化。直前は試験までの1か月、倍率1.3は重複なし、伴走費は対象外。
- 古いGoogleフォームから公式内の無料相談へ変更。許可した選択肢のみを相談文へ引き継ぐ。送信先・同意・個人情報処理は変更しない。
- 読み込み先に内容ハッシュを付与。編集元と本番成果物の両方をGitHubへ保存。
